# Text Classification Using TensorFlow

## Overview
This project implements a Text Classification model using TensorFlow to automatically categorize text into predefined classes. The model is trained on labeled text data and learns patterns in the text to make accurate predictions on new inputs.

## Problem Statement
Text data is generated in large quantities every day. Manually organizing and classifying this data is time-consuming. This project aims to automate the classification process using Deep Learning techniques.

## Technologies Used
- Python
- TensorFlow
- NumPy
- Pandas
- Scikit-learn
- Matplotlib

## Features
- Text preprocessing and cleaning
- Tokenization and text vectorization
- Deep Learning model using TensorFlow
- Training and evaluation of the model
- Prediction on new text inputs

## Dataset
The dataset consists of labeled text samples used for training and testing the classification model. The data is preprocessed before being fed into the neural network.

## Methodology
1. Data Collection
2. Data Preprocessing
3. Text Tokenization
4. Feature Extraction
5. Model Building using TensorFlow
6. Model Training
7. Model Evaluation
8. Prediction and Testing

## Results
The model successfully classifies text into different categories and achieves good performance on the test dataset.
